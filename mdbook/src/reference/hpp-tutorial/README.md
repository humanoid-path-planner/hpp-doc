# Tutorial for humanoid path planner platform.

This package provides some tutorials to learn how to use [Humanoid Path Planner](https://humanoid-path-planner.github.io/hpp-doc) software.
The various tutorials are:

1. [tutorial 1](./tutorial_1/) How to install and run the software.
2. [tutorial 2](./tutorial_2/) How to define and solve a simple pick and place problem.
3. [tutorial 3](./tutorial_3/) How to use HPP in manufacturing.
4. [tutorial 4](./tutorial_4/) How to control the trajectory of a tool.
5. [tutorial 5](./tutorial_5/) How to optimize and time-parameterize paths.
6. [tutorial 6](./tutorial_6/) How to use the rviz2 vizualization.
7. [tutorial 7](./tutorial_7/) How to execute motions on a simulated robot.
8. [tutorial 8](./tutorial_8/) Pick and place with gripper, introducing pre and post-actions.
9. [tutorial 9](./tutorial_9/) A more efficient way to assign pre or post-actions.
10. [exercise 10](./exercise_10/) Pick and place on the Stäubli robot on MFJA (https://accueil-mfja.iut-tlse3.fr)
