# C++ API

The C++ API of each package is documented with Doxygen.

When HPP is installed with its documentation, the documentation of the
installed version can be opened from `share/doc/hpp-doc/index.html` in the
installation prefix, for instance
`$DEVEL_HPP_DIR/install/share/doc/hpp-doc/index.html` or
`/opt/openrobots/share/doc/hpp-doc/index.html`.

The online documentation is generated by [Gepetto/doc](https://github.com/Gepetto/doc).
